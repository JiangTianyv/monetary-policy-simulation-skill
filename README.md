# monetary-policy-simulation-skill
> 货币银行学课程专属Skill：货币政策工具情景模拟器

## 项目简介
本项目为《货币银行学》学习工具，模拟央行三大传统货币政策工具：法定存款准备金率调整、公开市场业务、再贴现政策。输入不同政策参数，自动计算基础货币变动，模拟宽松/紧缩货币政策对市场流动性的影响，帮助理解货币政策传导机制。

## 功能
1. 法定准备金率调整模拟：改变准备金率，计算派生货币总量变化
2. 公开市场操作模拟：央行买卖债券，观察基础货币增减
3. 再贴现政策模拟：调整再贴现利率，分析商业银行借贷行为变化
4. 结果输出：文字解释政策属于紧缩还是宽松，附带货币银行学原理说明

## 技术实现
Python实现，命令行交互，无需额外依赖。

## 使用示例
> 选择工具：公开市场操作
> 央行买入债券500亿
> 输出：基础货币增加500亿，属于宽松货币政策，市场流动性提升。

## 学习收获
理解货币政策工具作用原理、基础货币、货币传导机制，巩固货币银行学核心考点。
